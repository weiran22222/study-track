# 执行计划 009：show 单任务查询

状态：实现完成，待主智能体审查

## 目标

实现 `SPEC.md` 2.4 节和 AC-12，使用户能够按 ID 查看一个任务，同时保持所有路径只读。

## 范围

- Application 提供按 ID 查询任务的用例；
- 新增 `show` CLI 子命令并注册到根命令；
- 复用 `list` 的 `[ ]` / `[x]` 单行展示协议；
- 添加 Application、CLI 和文件副作用测试；
- 更新本计划进度和实现决策。

## 非目标

- 不实现 `summary`；
- 不修改 JSON 格式或持久化写入逻辑；
- 不编辑、删除或完成任务；
- 不修改 SPEC、架构、CI、依赖或远程设置；
- 不解决另一个并行分支的冲突。

## 行为验收

1. 未完成和已完成任务分别输出 `[ ]` 与 `[x]`；
2. 存在任务退出 `0`，stdout 仅包含一行，stderr 为空；
3. 不存在任务退出 `2`，输出 `Task <id> not found.`；
4. 数据文件不存在时按任务不存在处理且不创建文件；
5. 成功和失败路径均保持原文件字节不变；
6. 非整数 ID 返回参数错误；
7. 损坏 JSON 返回退出码 `1`，不覆盖原文件；
8. JDK 21 下完整 `verify` 通过。

## 允许的共享热点

该切片可以最小修改 `StudyTaskService`、`StudyTrackCommand` 和现有 CLI 集成测试。不要为了
避免未来冲突而预先实现或重构 `summary`。冲突由两个 PR 都完成后统一处理。

## 实现决策

- `StudyTaskService.showTask(long)` 通过现有 `TaskRepository.findAll()` 只读端口精确查询，
  不扩展持久化端口或 JSON 格式；
- `ShowCommand` 沿用 `list` 的单行协议，并按现有 CLI 约定映射不存在与持久化异常；为减少
  并行共享热点，没有重构 `ListCommand`；
- Application 测试验证查询不调用写端口，CLI 集成测试以文件字节快照和文件不存在断言
  验证成功、失败及损坏 JSON 路径均只读。
