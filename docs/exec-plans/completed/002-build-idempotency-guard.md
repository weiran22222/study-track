# 执行计划 002：保护构建幂等性

状态：已完成

## 背景

主智能体在审查 `add` 垂直切片时连续运行 `verify`，发现 Maven Shade 会把上一次
已经聚合依赖的 JAR 再次作为输入，产生大量重复类警告。`maven-jar-plugin` 的
`forceCreation` 已修复根因，但尚无自动回归检查保护该配置。

## 人类决策

2026-07-27，用户选择方案 B：

- 在架构文档中声明构建幂等性不变量；
- 增加低成本测试，检查 `forceCreation` 保护配置；
- 不让 CI 连续执行两次完整 `verify`，避免当前阶段构建时间接近翻倍。

## 不变量

`mvnw verify` 必须可以在不执行 `clean` 的情况下重复运行。打包阶段不得把上一次
生成的聚合 JAR 作为下一次 Shade 的输入。

## 范围

- 更新 `ARCHITECTURE.md` 的验证流水线；
- 增加 `BuildConfigurationTest`；
- 更新本计划与根 `AGENTS.md` 的导航。

## 非目标

- 不修改产品行为；
- 不修改架构分层；
- 不降低现有门禁；
- 不增加第二次 CI 构建；
- 不把机器专属 Maven 镜像写进仓库。

## 验收

- 测试能从项目 `pom.xml` 中定位 `maven-jar-plugin`；
- `forceCreation` 必须为 `true`，缺失或为其他值时测试失败并提供修复方向；
- 完整 `verify` 通过；
- 文档说明这是一项针对已知根因的低成本保护，而非对所有构建幂等性问题的完备证明。
