# 决策卡 015：提交前检查完整暂存内容

状态：已批准

日期：2026-07-28

## 问题

普通 `git diff --check` 不覆盖未跟踪新文件，因此即使该命令通过，也不能证明所有准备提交
的新增文件已经接受空白错误检查。

## 人类决定

学习者于 2026-07-28 明确批准：提交前暂存精确预期文件，通过 `git status --short` 确认
所有预期文件都已进入暂存区，再对完整暂存内容运行 `git diff --cached --check`。

## 决定

- 只暂存本次变更精确预期的文件；
- 检查短状态，确认预期文件全部已暂存且没有意外暂存内容；
- 对将要提交的完整暂存内容运行 cached diff check；
- 不把普通 `git diff --check` 当成包含未跟踪新文件的完整检查。
