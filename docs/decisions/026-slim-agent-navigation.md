# 决策卡 026：精简智能体导航并分离操作工作流

状态：已实施（仓库内导航、工作流与机械检查）

日期：2026-07-29

## 问题

`AGENTS.md` 同时承担项目入口和完整操作手册。目标、文档地图与根本原则需要每次任务快速
读取，而风险分级、角色交接、分支操作、验证命令和失败诊断等细节只在修改仓库时完整使用。
把两类内容放在同一默认入口会扩大冷启动上下文，也让第一跳导航难以保持紧凑。

精简不能通过删减操作规则完成。现有权限、门禁、命令、职责与同 SHA 验证语义必须完整
保留，并在任何仓库修改前强制可发现。

## 用户选择

用户于 2026-07-29 明确选择：`AGENTS.md` 只保留项目目标、文档地图和根本原则，其余当前
有效操作性内容完整迁移到新的根级 `WORKFLOW.md`；任何仓库修改前必须读取该工作流。
这是位置与导航职责调整，按第二级小型 Harness 决策实施。

## 候选方案与取舍

### A. 保持单一 `AGENTS.md`

- 收益：没有第二个根级入口；
- 成本：每项任务默认加载完整操作手册，项目目标和第一跳地图继续被细节包围。

### B. `AGENTS.md` 保留入口与原则，`WORKFLOW.md` 承接完整操作规则

- 收益：默认入口更短，修改任务仍有单一、完整、强制读取的操作手册；两份文档职责清楚；
- 成本：修改仓库前多一次明确跳转，需要机械保护链接、必读语义和迁移完整性。

选择本方案。

### C. 把操作规则拆散到多个专题文件

- 收益：单个文件更短；
- 成本：操作者必须组合多份协议，容易漏读相互依赖的权限、角色和门禁，并增加链接漂移。

## 决定与语义守恒

- `AGENTS.md` 只保留“项目目标”“开始工作前：文档地图”“根本原则”三个二级章节，不保留
  三级操作章节；
- 文档地图把 `WORKFLOW.md` 标为任何仓库修改前必读，并继续保留当前权威文档、环境说明、
  历史索引和四类历史目录的渐进披露导航；
- `WORKFLOW.md` 逐项承接原 `AGENTS.md` 中权威事实与机械验收、关键边界、Harness 风险
  分级、工件职责、不变边界、角色流程与交接、暂存与验证、分支与本地 develop 更新、
  验证命令、完成定义和失败反馈；
- 除根级上下文链接和衔接说明外，不改变迁移内容的权限、门禁、命令、职责或验收语义；
- `DocumentationNavigationTest` 保护三个章节、必读入口、操作章节与关键边界，但不把
  完整历史文件清单复制到 `AGENTS.md`。

本决策只取代[决策卡 009](009-documentation-entropy-control.md)、
[决策卡 013](013-remove-volatile-harness-progress.md)及后续相关决策中“工作流细节必须位于
`AGENTS.md`”的位置约定。上述决策关于稳定导航、渐进披露、语义门禁和文档熵的其余决定
继续有效；既有操作规则本身没有被取代或放松。

## 不变边界

- 不改变 `SPEC.md`、`ARCHITECTURE.md`、`HARNESS.md`、产品行为或当前验收标准；
- 不删除、放松、重解释或新增智能体权限、Harness 风险等级、角色职责、受保护 PR、
  required `verify`、同 SHA 独立验证、分支流或本地 develop 规则；
- 不改变脚本、CI、依赖、远程设置或部署，不创建执行计划、证据或复盘；
- 不把本地迁移与自检写成 evaluator `PASS`、required CI、PR、合并或远程状态。

## 回退

若分离导致修改任务漏读操作规则或机械检查无法保护语义完整性，应通过新的受保护 Harness
PR 把操作章节原样恢复到 `AGENTS.md`，同步回退导航、索引和测试。回退不得删除规则、
降低门禁、跳过同 SHA evaluator 或绕过 required `verify`。

## 验收

- `AGENTS.md` 只有三个指定二级章节且没有三级操作章节；
- `WORKFLOW.md` 从地图和文档索引可发现，并明确任何仓库修改前必读；
- 原 `AGENTS.md` 的稳定操作章节、命令、权限、角色和门禁完整保留在 `WORKFLOW.md`；
- 根本原则保留不可妥协边界，但不复制操作手册；
- `docs/README.md` 索引 `WORKFLOW.md` 和本决策；
- 文档导航测试保护稳定语义与本地链接，不枚举完整历史文件到 `AGENTS.md`；
- JDK 21 环境检查、目标测试和完整 `.\mvnw.cmd verify` 通过。

验证结果只由实际执行后的 generator 自检和后续独立 evaluator 报告记录。
