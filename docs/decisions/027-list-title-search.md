# 决策卡 027：按标题字面子串筛选任务列表

状态：已批准，待规划 PR

日期：2026-07-29

## 问题

StudyTrack 的 `list` 只能查看全部任务或按完成状态筛选。任务增多后，用户无法用标题中的
已知文字缩小结果，只能读取完整列表。新增标题筛选会改变用户可观察的命令协议和验收
语义，即使保持只读且不改变数据格式，也属于必须规格先行的第三级产品变更。

这也是精简智能体导航并把操作规则分离到 `WORKFLOW.md` 后的第一个前瞻产品任务样本。
样本可用于观察当前 Harness 是否让智能体从短导航入口可靠找到产品权威、工作流、验证
入口和历史理由，但产品需求不能为了制造积极观察而扩大。

## 候选方案与取舍

### A. 保持现状

- 收益：不增加 CLI 参数、查询逻辑或测试维护面；
- 成本：任务较多时只能人工浏览完整列表。

### B. 为 `list` 增加单个字面子串筛选

- 收益：复用既有列表输出和状态筛选，以最小只读能力解决已知标题片段查询，并能与状态
  条件组合；
- 成本：必须明确 Unicode 长度、大小写、字面匹配、参数错误优先级、只读和损坏数据
  边界，并增加相应测试。

选择本方案。

### C. 一次提供忽略大小写、正则或模糊搜索

- 收益：查询能力更强；
- 成本：匹配语义、错误处理、依赖与测试空间明显扩大，超过当前问题所需的最小边界。

### D. 新增独立搜索命令

- 收益：可为未来搜索能力预留单独入口；
- 成本：与列表的排序、格式和状态筛选重复，当前没有足够需求支撑新的命令表面。

## 用户选择

用户于 2026-07-29 明确批准方案 B：为 `list` 增加 `--contains <text>`，并批准
[`SPEC.md` 2.2 节及 AC-18](../../SPEC.md#22-查看任务)中的产品边界与验收语义。完整命令
协议只以 `SPEC.md` 为权威，本决策不复制保存该协议。

## 产品边界

- 这是只读列表筛选，不改变 JSON 格式、任务字段、ID、状态、标题或 `nextId`；
- 复用既有列表排序、单行输出、状态筛选、空库和数据错误语义；
- 第一版只采用单个、区分大小写的字面子串条件，不增加忽略大小写、正则、模糊搜索、
  查询文件或高亮；
- 不改变其他命令、架构依赖方向、外部依赖、脚本、CI、权限、分支保护、远程设置或部署。

## 第三级流程

1. 本决策、`SPEC.md`、活动计划 022、前瞻观察 006 和文档索引先进入受保护的规划 PR；
2. 规划 PR 通过适用门禁并合入 `develop` 后，才可由 generator 在另一个受保护功能 PR
   实施批准范围；规划合入不表示功能已经实现；
3. 协调者冻结功能 Subject SHA，不同且不继承 generator 对话的 evaluator 对同一 SHA
   只读验证；修复产生新 SHA 时旧报告失效；
4. 只有 evaluator 结论与 required `verify` 覆盖同一功能 PR head，才可进入人类合并
   判断；合并后还必须确认精确最终 `develop` SHA 的 push `verify`；
5. 由于前瞻观察必须记录跨规划与功能 PR、并包含合并后才存在的最终 `develop` 验证，
   本样本需要一个受保护观察收尾 PR 回填真实证据、反例、成本和结论，并归档活动计划；
6. 所有阶段只记录实际发生的事实，不预写 generator 成功、evaluator `PASS`、CI、PR、
   合并、最终 `develop` 状态或 Harness 正向效果。

## Harness 观察理由

[前瞻观察 006](../feedback/006-list-title-search-observation.md)把本任务作为精简导航后的首个
真实产品样本，预注册观察当前导航、权威分工和 generator/evaluator 反馈回路能否在保留
人类产品决策的同时产生边界正确、可追踪且可复现的交付记录。现有任务没有可靠可比较
基线，单个样本最多建立现状并暴露反例，不能证明正向 Harness 效果。

观察必须区分人类本来就应作出的产品范围、重大取舍与合并决定，和规格批准后因导航、
协议或反馈不足而发生的非计划澄清、微观指挥或人工补救；前者不是失败指标，后者才是
待记录的掌舵负担与反馈信号。

## 回退

规划 PR 合并前可以关闭而不实施。功能尚未合并时，关闭功能 PR 即停止变更，不把未实现
协议描述为已完成；若规划规格需要撤回，通过新的受保护 PR 恢复 `SPEC.md` 和索引。

功能合入后若产品行为错误或维护成本不可接受，通过新的受保护 PR 移除 `--contains` 的
实现、测试和规格，保持已有数据文件无需迁移。回退不得改写 `develop` 历史、绕过
required `verify`、复用失效 evaluator 报告或删除前瞻观察中已经发生的反例。
